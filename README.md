# 온라인 회사 · 오늘도 적당히

출근은 했지만 조금 마음대로 쉬어 가는 브라우저용 3D 사무실입니다. 혼자 쉬기에서는 게임 속 상사·동료와 쉬고, 동료들과에서는 같은 기능에 최대 16명의 공동 플레이·대화·콕! 알림이 더해집니다. React와 Three.js로 화면을 만들고 Vinext/Sites와 D1으로 실행합니다.

## 할 수 있는 일

- 내 자리에 앉아 업무·쇼핑·미니게임·졸기 전환, 의자 돌리기
- 큰 개인 할 일 목록에서 추가·수정·완료·삭제, 업무 중 키보드 ASMR
- 남성 짧은 머리·여성 포니테일 캐릭터 선택
- 출퇴근 시간을 입력하고 실시간 퇴근 카운트다운 확인
- 멀티 동료에게 콕! 찌르기와 개인 알림함
- 옥상과 사무실을 회전 전환으로 오가며 사탕 빨기
- 상사의 관찰을 알아차리고 2초 안에 업무로 복귀하기
- 펀치·뿅망치·서류 뭉치로 상사를 골탕먹이기
- 커피 내리기와 세 모금 마시기, 과자 세 종류를 총 여섯 개까지 챙기고 먹기
- 서로 다른 일상을 보내는 동료 셋과 함께 사무실에서 쉬기

상사 옆에 간격을 두고 마주 서서 공격하며, 도구마다 준비·타격·회복 동작이 다릅니다. 탕비실에서는 컵을 들고 커피를 마시거나 과자를 집어 주머니에 넣고 먹는 동작이 표시됩니다. 먹고 마시는 동안 주머니 창은 잠깐 접혀 동작을 보여주고, 행동이 끝나면 다시 열립니다.

개발 기준 저장소는 [Choi-SeoJun/online-office](https://github.com/Choi-SeoJun/online-office)입니다. [로그인 없는 공개 플레이 주소](https://office-break-01a1bf07.mobilechrysanthemum1.chatgpt.site)에서 현재 배포본을 확인할 수 있습니다.

적발이나 타격에 따른 해고·체력·사망·소지품 손실은 없습니다. 회원 가입, 결제, 외부 AI 호출은 포함하지 않습니다.

## 동료들과 함께하기

시작 화면에서 **동료들과**를 선택합니다. 회사 이름과 정원(2–16명)을 정해 방을 만들거나, 8자리 코드·초대 링크로 입장할 수 있습니다. 각자 고정된 번호의 책상을 배정받으며 칸막이가 있는 마주 보는 책상 줄이 정원에 맞춰 늘어납니다. 방장은 동료 목록에서 정원을 변경할 수 있습니다.

상사 장난, 업무·쇼핑·미니게임·졸기·의자 돌리기, 커피·과자, 옥상 벤치·네 벽에 기대기·사탕과 바람 소리를 혼자 쉬기와 동일하게 이용합니다. 상사는 모두에게 같은 위치와 타격 반응으로 보이고, 동료들은 같은 층에 있을 때만 화면에 나타납니다. 방장이 옥상으로 이동해도 사무실 상사는 남아 있습니다. 이동과 휴식·섭취 동작, 글 채팅을 공유합니다. 채팅창 왼쪽 위 모서리를 끌어 크기를 바꿀 수 있고 크기는 이 브라우저에 저장됩니다. 해당 모서리에 키보드 초점을 두고 방향키로도 조절할 수 있습니다. 채팅은 캐릭터 위에도 약 9초간 표시되며 Enter로 전송, Shift+Enter로 줄을 바꿉니다. 할 일과 출퇴근 시간은 개인 브라우저에만 저장되며 방으로 보내지 않습니다. 동료 캐릭터를 누르거나 동료 목록의 **콕!** 버튼으로 개인 알림을 보낼 수 있습니다. 알림은 대상 동료에게만 보이며 종 모양 알림함을 열면 읽음으로 표시됩니다. 연속 전송은 5초 간격이며 최근 100개 알림을 유지합니다. 방은 생성 후 24시간 동안 이용할 수 있고 최근 100개 대화를 유지합니다. 연결이 끊긴 자리는 120초간 예약되며, 방장이 나가거나 연결이 오래 끊기면 남은 동료에게 방장 권한이 넘어갑니다.

참여 정보는 탭의 sessionStorage에 저장하고 서버에는 토큰 해시만 저장합니다. 초대 링크에는 방 코드만 포함합니다. 멀티 데이터는 D1에 저장하며 짧은 HTTP 동기화와 화면 보간으로 참여자의 움직임을 표시합니다.

## 조작

| 행동 | PC | 휴대전화 |
| --- | --- | --- |
| 이동 | 바닥 클릭, WASD·방향키 | 바닥 탭 |
| 장소 선택 | 물건·상사 클릭 또는 장소 버튼 | 물건·상사 탭 또는 장소 버튼 |
| 기본 행동 | 도착 후 행동 버튼 또는 E | 도착 후 행동 버튼 |
| 업무로 복귀 | 업무 버튼 또는 Space | 업무 버튼 |
| 타격 | 도구 선택 후 ‘한 대 치기’ | 동일 |
| 소지품 사용 | 주머니에서 먹기·한 모금 | 동일 |
| 층 이동 | 옥상으로 / 사무실로 버튼 | 동일 |
| 할 일 작성 | 업무 화면에서 입력·Enter 추가 | 입력 후 추가 버튼 |
| 출퇴근 시간 | 상단 시계 버튼 | 동일 |
| 콕! 찌르기 | 동료 클릭 또는 동료 목록 | 동료 탭 또는 동료 목록 |
| 확대·축소 | 마우스 휠 또는 +/− | +/− |
| 화면 회전·높이 | 상하좌우 드래그 | 상하좌우 드래그 |
| 취소·닫기 | Esc 또는 화면 버튼 | 화면 버튼 |

대상 선택은 접근만 실행합니다. 착석·제조·획득·공격은 별도 행동이 필요하며, E로 공격하지 않습니다. 설정에서 소리, 움직임 줄이기, 그래픽 품질을 바꿀 수 있습니다. 다른 탭으로 전환하면 게임 진행과 소리가 멈춥니다. 소리는 기본으로 꺼져 있으며 상단 스피커 버튼으로 켭니다. 움직임 줄이기는 층 전환의 회전을 짧은 페이드로 바꿉니다.

## 실행과 확인

Node.js **22.13.0 이상**이 필요합니다. 프로젝트 폴더에서 실행합니다.

```sh
npm ci
npm run dev
```

개발 서버가 출력하는 주소를 엽니다. 독립 실행 환경의 기본 포트는 5173이며, 필요하면 `npm run dev -- --port 5174`처럼 지정합니다. 설치는 중복 실행하지 않습니다.

```sh
npm test
npm run typecheck
npm run build
```

`npm test`는 이동·관찰·타격·소지품·저장 등의 상태 전이를 확인합니다. `npm run typecheck`는 타입 검사를, `npm run build`는 배포용 빌드를 수행합니다. 빌드 후 `npm start`로 완성된 Worker를 로컬에서 미리 볼 수 있습니다. 이 명령은 배포하지 않습니다.

멀티를 처음 로컬 실행할 때는 빌드 후 로컬 D1에 아래 마이그레이션을 번호순으로 한 번씩 적용합니다. 기존 설치를 업데이트할 때는 아직 적용하지 않은 SQL만 실행합니다. 이미 적용한 SQL은 반복하지 않습니다. 공개 배포에는 Sites가 마이그레이션을 적용합니다.

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_flat_ezekiel_stane.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0001_breezy_prowler.sql
```

Sites 환경에서는 제공되는 설치·미리보기·빌드·소스 동기화·배포 도우미의 순서를 따릅니다. 잠금 파일 기반 설치 래퍼는 `npm run install:ci`입니다. 환경별 세부 절차와 호스팅·인증·선택적 데이터베이스 안내는 [스타터 참고 문서](docs/starter-reference.md)에 보존했습니다.

## 저장과 첫 버전 범위

개인 할 일은 최대 200개, 항목당 200자로 저장하며 추가·수정·완료·삭제와 필터를 제공합니다. 출퇴근 시계는 기기의 현재 시각을 사용하며 퇴근이 출근보다 이르면 다음 날 퇴근으로 계산합니다. 저장 실패 시 화면에 알리고 현재 탭 메모리에 보존합니다. 새로고침하면 저장하지 못한 내용이 사라질 수 있습니다. 기존 업무 시트 저장값은 그대로 남겨두며 게임 초기화도 개인 할 일·출퇴근 시간·기존 시트 데이터를 지우지 않습니다.

이름, 캐릭터, 선택한 도구, 소리·움직임·품질 설정, 간식 수량은 현재 기기·브라우저의 로컬 저장소에 저장합니다. 커피와 남은 모금, 현재 행동, NPC 위치는 임시 상태이며 다시 접속하면 초기화됩니다. 저장을 사용할 수 없어도 현재 세션은 계속 플레이할 수 있습니다. 다른 기기나 브라우저로 자동 동기화하지 않습니다.

첫 버전에서는 마지막 모금을 마신 뒤 빈 머그를 별도로 보관하지 않습니다. 동료의 반응은 정해진 간단한 동작으로, 환경음과 행동 소리는 가벼운 합성음으로 구현했습니다. 설계안의 세부 연출을 모두 재현한 버전은 아닙니다.

호스팅은 사용자 요청으로 **링크를 가진 누구나 GPT 로그인 없이 플레이하는 공개 범위**입니다. GitHub 소스 저장소의 공개 범위와는 별개이며, 이후 배포에서도 이 공개 설정을 유지합니다.

실제 휴대전화 하드웨어에서의 터치·발열·배터리·그래픽 호환성과 FPS는 아직 측정하지 않았습니다. PC 60fps·모바일 30fps는 목표이며 보장 수치가 아닙니다. 자동 상태 검사와 브라우저 화면 검증은 실제 기기 성능 검증을 대신하지 않습니다.

배포 산출물은 소스 밖이나 무시되는 `outputs/`에 보관합니다. `.env*`, `.dev.vars*`, `.sites-runtime/`, `.wrangler/`, `.vinext/` 등 자격 증명·로컬 실행 상태는 업로드하지 않습니다. 이 구성은 `wrangler.jsonc`를 사용하지 않습니다.
