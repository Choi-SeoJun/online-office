# 온라인 회사 · 오늘도 적당히

출근은 했지만 조금 마음대로 쉬어 가는 브라우저용 3D 사무실입니다. 혼자 쉬기에서는 게임 속 상사·동료와 쉬고, 동료들과에서는 같은 기능에 최대 16명의 공동 플레이·대화·콕! 알림이 더해집니다. React와 Three.js로 화면을 만들고 Vinext/Sites와 D1으로 실행합니다.

## 할 수 있는 일

- 내 자리에 앉아 업무·쇼핑·미니게임·졸기 전환, 의자 돌리기
- 큰 개인 할 일 목록에서 추가·수정·완료·삭제, 업무 중 키보드 ASMR
- 남성 짧은 머리·여성 포니테일 캐릭터 선택
- 출퇴근 시간을 입력하고 실시간 퇴근 카운트다운 확인
- 멀티 동료에게 콕! 찌르기와 개인 알림함
- 로그인 없이 비공개 건의함에 불편한 점·개선 제안 남기기
- 옥상과 사무실을 회전 전환으로 오가며 사탕 빨기
- 상사의 관찰을 알아차리고 2초 안에 업무로 복귀하기
- 펀치·뿅망치·서류 뭉치로 상사를 골탕먹이기
- 커피 내리기와 세 모금 마시기, 과자 세 종류를 총 여섯 개까지 챙기고 먹기
- 서로 다른 일상을 보내는 동료 셋과 함께 사무실에서 쉬기

상사 옆에 간격을 두고 마주 서서 공격하며, 도구마다 준비·타격·회복 동작이 다릅니다. 탕비실에서는 컵을 들고 커피를 마시거나 과자를 집어 주머니에 넣고 먹는 동작이 표시됩니다. 먹고 마시는 동안 주머니 창은 잠깐 접혀 동작을 보여주고, 행동이 끝나면 다시 열립니다.

개발 기준 저장소는 [Choi-SeoJun/online-office](https://github.com/Choi-SeoJun/online-office)입니다. [로그인 없는 공개 플레이 주소](https://choi-seojun.github.io/online-office/)에서 현재 배포본을 확인할 수 있습니다.

적발이나 타격에 따른 해고·체력·사망·소지품 손실은 없습니다. 회원 가입, 결제, 외부 AI 호출은 포함하지 않습니다.

## 동료들과 함께하기

시작 화면에서 **동료들과**를 선택합니다. 회사 이름과 정원(2–16명)을 정해 방을 만들거나, 8자리 코드·초대 링크로 입장할 수 있습니다. 각자 고정된 번호의 책상을 배정받으며 칸막이가 있는 마주 보는 책상 줄이 정원에 맞춰 늘어납니다. 방장은 동료 목록에서 정원을 변경할 수 있습니다.

상사 장난, 업무·쇼핑·미니게임·졸기·의자 돌리기, 커피·과자, 옥상 벤치·네 벽에 기대기·사탕과 바람 소리를 혼자 쉬기와 동일하게 이용합니다. 상사는 모두에게 같은 위치와 타격 반응으로 보이고, 동료들은 같은 층에 있을 때만 화면에 나타납니다. 방장이 옥상으로 이동해도 사무실 상사는 남아 있습니다. 이동과 휴식·섭취 동작, 글 채팅을 공유합니다. 채팅창 왼쪽 위 모서리를 끌어 크기를 바꿀 수 있고 크기는 이 브라우저에 저장됩니다. 해당 모서리에 키보드 초점을 두고 방향키로도 조절할 수 있습니다. 채팅은 캐릭터 위에도 약 9초간 표시되며 Enter로 전송, Shift+Enter로 줄을 바꿉니다. 할 일과 출퇴근 시간은 개인 브라우저에만 저장되며 방으로 보내지 않습니다. 동료 캐릭터를 누르거나 동료 목록의 **콕!** 버튼으로 개인 알림을 보낼 수 있습니다. 알림은 대상 동료에게만 보이며 종 모양 알림함을 열면 읽음으로 표시됩니다. 연속 전송은 5초 간격이며 최근 100개 알림을 유지합니다. 방은 생성 후 24시간 동안 이용할 수 있고 최근 100개 대화를 유지합니다. 연결이 끊긴 자리는 120초간 예약되며, 방장이 나가거나 연결이 오래 끊기면 남은 동료에게 방장 권한이 넘어갑니다.

참여 정보는 탭의 sessionStorage에 저장하고 서버에는 토큰 해시만 저장합니다. 초대 링크에는 방 코드만 포함합니다. 멀티 데이터는 D1에 저장하며 짧은 HTTP 동기화와 화면 보간으로 참여자의 움직임을 표시합니다.

## 비공개 건의함

솔로·멀티 화면 상단의 **건의함**에서 분류와 내용을 적어 보내면 운영자에게만 전달됩니다. 로그인이나 연락처는 필요하지 않으며, 작성 내용과 현재 모드·층만 보냅니다. 채팅, 개인 할 일, 방 참여 정보는 함께 전송하지 않습니다. 실패하면 작성 내용이 남아 다시 전송할 수 있습니다. 건의는 게임 방과 별도로 저장되므로 방이 종료되어도 사라지지 않습니다.

운영자는 [관리자 건의함](https://office-break-01a1bf07.mobilechrysanthemum1.chatgpt.site/admin/feedback)에 운영자 ChatGPT 계정으로 로그인해 확인합니다. 새 의견·검토 완료 필터, 이전 의견 불러오기, 검토 완료/되돌리기를 지원합니다. 일반 플레이는 계속 로그인 없이 이용할 수 있습니다. 관리자 화면과 API는 서버에서 운영자 계정을 확인하며 다른 계정에는 건의 내용을 반환하지 않습니다.

서버 설정 `FEEDBACK_ADMIN_EMAIL`은 운영자 로그인 이메일, `FEEDBACK_RATE_SECRET`은 제출 빈도 제한용 무작위 비밀값입니다. 둘 다 Sites의 비밀 환경 변수로 보관하고 변경 후 다시 배포합니다. 값은 소스나 Pages 빌드에 넣지 않습니다. 설정이 없으면 제출 또는 관리자 조회가 실패하도록 처리합니다. 로컬 개발에서는 무시되는 `.dev.vars`에 테스트 값만 넣습니다. 개발용 관리자 이메일 `seedy@sites.test`와 로컬 `/signin-with-chatgpt?return_to=/admin/feedback`은 개발 서버에서만 작동합니다.

## 실행과 확인

Node.js **22.13.0 이상**이 필요합니다. 프로젝트 폴더에서 실행합니다.

```sh
npm ci
npm run dev
```

개발 서버가 출력하는 주소를 엽니다. 독립 실행 환경의 기본 포트는 5173이며, 필요하면 `npm run dev -- --port 5174`처럼 지정합니다. 설치는 중복 실행하지 않습니다.

```sh
npm test
npm run typecheck
npm run build
```

`npm test`는 이동·관찰·타격·소지품·저장 등의 상태 전이를 확인합니다. `npm run typecheck`는 타입 검사를, `npm run build`는 배포용 빌드를 수행합니다. 빌드 후 `npm start`로 완성된 Worker를 로컬에서 미리 볼 수 있습니다. 이 명령은 배포하지 않습니다.

멀티를 처음 로컬 실행할 때는 빌드 후 로컬 D1에 아래 마이그레이션을 번호순으로 한 번씩 적용합니다. 기존 설치를 업데이트할 때는 아직 적용하지 않은 SQL만 실행합니다. 이미 적용한 SQL은 반복하지 않습니다. 공개 배포에는 Sites가 마이그레이션을 적용합니다.

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_flat_ezekiel_stane.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0001_breezy_prowler.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0002_shocking_maelstrom.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0003_office_feedback.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0004_office_board.sql
```

Sites 환경에서는 제공되는 설치·미리보기·빌드·소스 동기화·배포 도우미의 순서를 따릅니다. 잠금 파일 기반 설치 래퍼는 `npm run install:ci`입니다. 환경별 세부 절차와 호스팅·인증·선택적 데이터베이스 안내는 [스타터 참고 문서](docs/starter-reference.md)에 보존했습니다.

## GitHub Pages 배포

공개 플레이 주소는 https://choi-seojun.github.io/online-office/ 입니다. `main`에 반영하면 GitHub Actions가 타입 검사·테스트·정적 빌드를 거쳐 Pages에 배포합니다. Pages에는 게임 화면과 정적 파일만 올라가며, 방·채팅·동기화는 기존 Sites의 `/api/rooms`와 D1을 사용합니다. 백엔드 변경은 기존 Sites 배포도 함께 진행해야 합니다.

```sh
npm run build:pages
npm run preview:pages
```

정적 진입점은 `web/`, 설정은 `vite.pages.config.ts`, 결과물은 `dist-pages/`입니다. Pages용 API 주소와 `/online-office/` 경로는 빌드 시 고정하며 방문자가 입력한 주소를 사용하지 않습니다. 백엔드는 같은 출처 및 `https://choi-seojun.github.io`에서 온 요청만 허용합니다. 로컬 정적 미리보기에서는 멀티 연결이 허용되지 않으므로 멀티 개발은 기존 `npm run dev`를 사용합니다.

주소별 브라우저 저장 공간은 분리됩니다. 기존 주소의 업무 화면에서 **내보내기**로 할 일을 저장한 뒤 새 주소에서 **가져오기**를 선택하면 내용과 완료 표시를 옮길 수 있습니다. 가져오기는 기존 항목을 덮어쓰지 않으며 파일은 서버에 전송하지 않습니다. 기존 Sites 주소도 계속 이용할 수 있습니다.

## 저장과 첫 버전 범위

**최근 업데이트 소식**은 한국 시간 **매일 오전 4시**에 공개합니다. 직전 오전 4시부터 공개 직전까지의 변경을 하나의 공지로 묶습니다. 예를 들어 11월 12일 23시와 11월 13일 03시의 수정은 **11월 13일 04시 공지**에 함께 실립니다. 변경이 없는 날에는 새 공지를 만들지 않습니다. 공지 원본은 `game/updates.ts`이며 날짜 키는 공개 날짜입니다. 이후 변경을 배포할 때 `announcementDateForChange(Date.now())`로 다음 공지 날짜를 구해 그 항목에 이어 적고, 공개된 공지는 유지합니다.

공개 시각이 된 새 공지는 접속할 때 자동으로 한 번 열립니다. 읽음 기록은 현재 브라우저에 저장하여 새로고침·솔로/멀티 전환 후에도 유지하고, 이미 읽은 공지는 시작 화면이나 게임 안의 **업데이트 소식** 버튼으로 다시 볼 수 있습니다. 공개 전 공지는 목록에 표시하거나 읽음 처리하지 않습니다. 켜 둔 화면은 공개 시각과 탭 복귀 때 다시 확인하고, 다른 창을 읽는 중에는 그 창을 닫은 뒤 공지를 보여줍니다. 이후 배포에서 추가된 내용은 새로 접속하거나 새로고침해야 불러옵니다. 다른 브라우저·기기나 브라우저 저장 데이터 삭제 후에는 읽음 기록이 공유되지 않습니다. 저장 기능이 차단된 환경에서는 현재 방문 동안만 읽음을 기억합니다. 공지 아래의 **의견 남기기**는 기존 비공개 건의함으로 연결됩니다.

**게시판**에서 정보 글(2,000자), 포스트잇(280자), 직접 그린 낙서를 최대 50개까지 붙일 수 있습니다. 솔로 게시판은 현재 브라우저에 개인용으로 저장됩니다. 멀티 게시판은 같은 방의 참여자끼리 공유하며, 기존 방의 24시간 수명 동안 유지됩니다. 본인 게시물은 작성자가, 방의 게시물은 현재 방장이 떼어낼 수 있습니다. 멀티 게시판에는 초대 코드만으로 접근할 수 없으며 유효한 참여 세션이 필요합니다. 개인 할 일이나 관리자 건의함과 별도로 보관합니다.

사무실 뒤쪽은 왼쪽부터 **부장님 자리 → 프린터 → 파티션 → 간식 → 커피 → 휴식 공간**으로 구성됩니다. 2.35 높이의 불투명 파티션이 부장님 자리에서 휴게 공간을 가리고, 앞쪽 통로로 오갈 수 있습니다. 솔로와 멀티가 같은 배치 원칙을 사용하며 작은 멀티 방도 휴게 공간의 폭을 확보합니다. 가구·이동·좌석은 `game/office-plan.ts`의 배치를 공유합니다.

탕비실에는 네 개의 휴식 의자, 옥상 벤치에는 세 자리가 있습니다. 같은 자리는 한 명만 사용할 수 있도록 서버에서 확인합니다. 의자 돌리기는 사람과 의자가 함께 회전하고, **춤추기**는 8초 동안 미러볼과 조명 아래에서 춤을 춥니다. 이동하거나 취소하면 멈춥니다. 업무 중 타이핑과 한숨 동작은 동료에게도 보이며, 움직임 줄이기 설정을 따릅니다.

개인 할 일은 최대 200개, 항목당 200자로 저장하며 추가·수정·완료·삭제와 필터를 제공합니다. 출퇴근 시계는 기기의 현재 시각을 사용하며 퇴근이 출근보다 이르면 다음 날 퇴근으로 계산합니다. 저장 실패 시 화면에 알리고 현재 탭 메모리에 보존합니다. 새로고침하면 저장하지 못한 내용이 사라질 수 있습니다. 기존 업무 시트 저장값은 그대로 남겨두며 게임 초기화도 개인 할 일·출퇴근 시간·기존 시트 데이터를 지우지 않습니다.

이름, 캐릭터, 선택한 도구, 소리·움직임·품질 설정, 간식 수량은 현재 기기·브라우저의 로컬 저장소에 저장합니다. 커피와 남은 모금, 현재 행동, NPC 위치는 임시 상태이며 다시 접속하면 초기화됩니다. 저장을 사용할 수 없어도 현재 세션은 계속 플레이할 수 있습니다. 다른 기기나 브라우저로 자동 동기화하지 않습니다.

첫 버전에서는 마지막 모금을 마신 뒤 빈 머그를 별도로 보관하지 않습니다. 동료의 반응은 정해진 간단한 동작으로, 환경음과 행동 소리는 가벼운 합성음으로 구현했습니다. 설계안의 세부 연출을 모두 재현한 버전은 아닙니다.

호스팅은 사용자 요청으로 **링크를 가진 누구나 GPT 로그인 없이 플레이하는 공개 범위**입니다. GitHub 소스 저장소의 공개 범위와는 별개이며, 이후 배포에서도 이 공개 설정을 유지합니다.

실제 휴대전화 하드웨어에서의 터치·발열·배터리·그래픽 호환성과 FPS는 아직 측정하지 않았습니다. PC 60fps·모바일 30fps는 목표이며 보장 수치가 아닙니다. 자동 상태 검사와 브라우저 화면 검증은 실제 기기 성능 검증을 대신하지 않습니다.

배포 산출물은 소스 밖이나 무시되는 `outputs/`에 보관합니다. `.env*`, `.dev.vars*`, `.sites-runtime/`, `.wrangler/`, `.vinext/` 등 자격 증명·로컬 실행 상태는 업로드하지 않습니다. 이 구성은 `wrangler.jsonc`를 사용하지 않습니다.
