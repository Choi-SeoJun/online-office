# Korean weather region data

Source: Korea Meteorological Administration (기상청), **기상청41_단기예보 조회서비스_오픈API활용가이드_격자_위경도(2610).xlsx**, sheet `최종 업데이트 파일_20260930`, downloaded 2026-11-13 from the [official public data portal](https://www.data.go.kr/data/15084084/openapi.do). Portal attachment `FILE_000000007732424`, detail `1`, ZIP SHA-256 `9dfd7dc2d422318154d3484fb00142afa3c5271fc14d079adf997043a14b86ba`.

The portal permits reuse with source attribution (Public Nuri Type 1, as indicated on its listing). Visible attribution is included in the weather panel. These are **region representative points**, not surveyed boundaries or exact local observations. Current precipitation now uses KMA observations; see [KMA weather](kma-weather.md). Open-Meteo is the explicitly labelled fallback.

`game/korea-region-points.ts` retains the older city-level selections and two-decimal coordinates for saved preferences and installed clients. Its synthetic city points average non-autonomous districts. `game/korea-local-points.ts` adds 3,836 official points including 3,565 읍·면·동 points, six-decimal representative coordinates, and the original integer `nx`/`ny` grid. Generate it with `python scripts/generate-korea-local-points.py path/to/kma-2610.zip` (Python + openpyxl); the generator checks the source ZIP hash above.

The hierarchy preserves synthetic city IDs, splits `천안시서북구` into `천안시 → 서북구`, and attaches neighborhoods to their official districts. Metro cities go directly to their constituent 구/군, counties go to 읍/면, and Sejong skips its duplicate city level. Province, city and district representative choices remain available; selecting a parent clears its former descendants. Marine-only Ieodo is excluded.

The 2026 source includes **전남광주통합특별시**, established on 2026-07-01 ([official city site](https://www.jeonnam-gwangju.go.kr/)). It has a direct representative selection and optional constituent cities/counties/districts. Its broader area must not be silently collapsed to the former Gwangju footprint. Older Gwangju preference maps to the former city area's Seo-gu representative point. Other known old domestic choices migrate; foreign preferences fall back to Seoul.

Opt-in geolocation requests a fresh high-accuracy device position and computes the haversine-nearest **neighborhood** representative point locally. Province/city centers are not candidates. No raw device coordinates are stored or sent. A broad regional eligibility envelope prevents far-away foreign locations from selecting a Korean point; it is not a legal-border geofence. The selected domestic name is always visible, and manual selection is available. Only its known administrative ID goes to the server, which resolves the official grid; no arbitrary GPS coordinates or client-supplied grid is accepted. Legacy city-coordinate requests still work. Browser forecast caches use region IDs, so rounding cannot alias nearby neighborhoods. Upstream observation requests share work for the same KMA grid and publication cycle. Room payloads remain unchanged.

These are approximately **5 km forecast/observation grids**, not street-level sensors or administrative boundary polygons. Neighboring neighborhoods can share one grid. A nearest administrative point need not be the device's legal address, and device accuracy and publication delay still affect the result. The weather panel explains grid granularity.

## Legal address names and current administrative updates

Address source: Ministry of the Interior and Safety, [administrative-code release posted 2026-11-18](https://www.mois.go.kr/frt/bbs/type001/commonSelectBoardArticle.do?bbsId=BBSMSTR_000000000052&nttId=131063), code files dated **2026-11-11**. ZIP attachment `FILE_00150639clSC0wx`, file `1`, SHA-256 `5b4493acbb3d2a130ffc5a9d8fc2b2e860d1386156a7faef918b065fef91dcde`. Visible attribution is in the weather dialog. Generate with `python scripts/generate-korea-addresses.py path/to/mois-20261111.zip`; only Python standard libraries are needed. Fixed-width fields are CP949 **byte** fields.

`KIKcd_B` supplies 5,067 current legal 읍·면·동 (excluding 리 and upper levels); `KIKcd_H` supplies 3,631 administrative neighborhoods including branch offices; `KIKmix` supplies their official many-to-many jurisdiction mapping. Every legal neighborhood has a mapping, and every current administrative ID resolves. This is an 읍·면·동 catalog, not a street/building-address or 리 geocoder. The generated file contains only names, codes and relationships, with no player locations.

The earlier KMA list was complete for its own 2026-09-30 workbook but used administrative names, so 2,995 legal names were not independently findable by matching the local name and parent path. Address/admin pairs now have stable allowlisted IDs such as `address:4413310400:4413358000`. 두정동 offers 부성1동 and 부성2동; the full province/city/district path distinguishes other places named 두정동. Identical legal/admin names reuse the administrative selection. Search runs locally and lists at most 40 matches with a total and refinement hint; all choices also appear in the appropriate dropdown. Shared browser preference storage preserves the selected address across reloads, solo and multiplayer.

The MOIS release adds 68 entries absent from the KMA workbook: 고덕1동/고덕2동 and 66 branch-office entries, and corrects 송림3·5동 typography. [The 고덕 split took effect 2026-10-12](https://www.mois.go.kr/frt/bbs/type001/commonSelectBoardArticle.do?bbsId=BBSMSTR_000000000052&nttId=130109). Old 고덕동 remains readable for installed clients and saved choices, but is hidden from new direct selections; the UI asks the player to choose a current jurisdiction. KMA's special 독도 point is retained.

Newly included administrative entries lack separate coordinates in the KMA workbook, so they explicitly use existing representative points: 고덕1/2동 use old 고덕동; branch offices generally use their parent 읍/면; reviewed exceptions 원산출장소→오천면, 신수출장소→사천시, 삼랑진임천출장소→삼랑진읍. The UI names this fallback, without claiming street-level accuracy. The generator fails on unknown/unreviewed mappings instead of dropping them. GPS nearest-point search excludes copied fallback coordinates, address aliases and retired points. The server resolves only known IDs to existing grids and coalesces upstream requests by grid; secrets and arbitrary GPS coordinates are never exposed. These data files are versioned snapshots, not a live administrative-code feed; future code releases require regeneration and review.

Legal address parents are preserved separately from administrative jurisdiction. For example, 만안구 안양동 partly maps to 동안구 비산1동; it stays selectable/searchable under 만안구 and displays the cross-district jurisdiction explicitly. Search reuses one Korean collator and a pre-sorted index so broad input does not repeatedly sort thousands of names while the game renders.
