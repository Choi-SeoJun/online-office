# 첫 버전 검증 기록

2026-11-09, Windows 개발 환경과 내장 브라우저에서 확인했습니다.

- 상태·저장 자동 검사 17개 통과: 경로와 충돌, 접근과 별도 행동, 상사 관찰과 복귀, 공격 간격, 커피·간식 중복 방지와 취소, 저장 오류 처리, 일시정지.
- 전체 TypeScript 검사 통과. Sites 배포 빌드 성공. Three.js 장면 청크가 500 KB를 넘는 빌드 안내는 남아 있으며 오류는 아닙니다.
- 브라우저 직접 조작: 출근, 장소 이동, 책상 착석, 업무·쇼핑·미니게임·졸기, 쇼핑 상품 변경, 반짝이는 칸 누르기.
- 주머니를 연 상태에서 Space로 즉시 업무 복귀 확인.
- 커피 제조 후 3모금, 마시기 후 2모금 확인. 쿠키 획득, 먹기 취소 시 수량 유지, 완료 시 수량 차감 확인.
- 펀치·뿅망치·서류 부채 선택과 타격 반응, 탕비실 착석 확인.
- 새로고침 후 간식 1개 유지와 커피 0모금 초기화 확인. 설정 열기·움직임 줄이기 변경·Esc 닫기 확인.
- 1280×800, 390×844, 667×375 화면에서 배치 확인. 가로 667 화면의 모니터 오른쪽 217px, 행동판 왼쪽 236px로 겹침 없음. 모바일 세로·가로에서 가로 스크롤 없음.
- 새로고침 후 실행 오류 없음. 구형 그림자 옵션 경고는 PCFShadowMap 변경으로 수정했습니다.

리뷰에서 발견한 접근 취소 후 재이동, 짧은 행동 중 업무 복귀 불가, 주머니가 Space를 막는 문제를 수정했습니다. 커피를 들고 있는 표시도 추가했습니다. 그래픽 장치 오류 시 정지·재시도 경로는 소스로 확인했고 실제 장치 오류를 발생시키는 검사는 수행하지 않았습니다.

실제 휴대전화, 프레임 속도, 발열·배터리, 모든 브라우저 조합은 검증하지 않았습니다. 소리는 합성음이며 동료 반응은 간단한 정해진 동작입니다. 마지막 모금 이후 빈 컵은 유지하지 않습니다. 호스팅 배포 결과는 별도 배포 응답으로 확인합니다.
