# 캐릭터 상호작용 수정 검증

## 변경과 원인

- 상사 추적의 목적지가 상사의 중심이어서 두 캐릭터 간격이 0.037까지 줄어드는 문제를 재현했습니다. 가구를 피하면서 옆으로 접근하고, 서로 마주 보고 멈추도록 수정했습니다. 공격은 거리 1.5 이내와 화면 가로 방향 간격 0.9 이상을 모두 만족할 때 가능합니다.
- 이동 중 공격하면 경로와 이동 입력을 정지하고 도구별 준비·타격·회복 동작을 유지합니다. 펀치 0.55초, 뿅망치 0.85초, 서류 부채 0.7초이며 효과는 타격 시점에 맞춰 표시합니다.
- 커피 내리기 3.2초, 과자 챙기기 1.3초, 먹기 1.5초, 마시기 1.6초로 컵과 선택한 과자가 손에 표시됩니다. 의자에 기대는 자세는 다리를 앉은 상태로 유지합니다.
- 마시기·먹기 중에는 주머니 창을 잠깐 숨기고 종료 시 복원합니다. 탕비실 동료의 커피 위치를 분리했습니다.
- 리뷰에서 발견한 책상 모서리 이동 정지는 간격별 표본 검사에서 놓친 좁은 충돌이 원인이었습니다. 선분과 확장된 가구 사각형, 상사 주변 원 사이의 충돌을 정확하게 계산하도록 바꿨습니다.

## 확인 결과

- 전체 자동 검사 **37개 통과**. 실제 Three.js 캐릭터 구조의 컵·과자·무기 위치와 종료 시 정리, 일반/움직임 줄이기 모드의 타격 접촉을 포함합니다.
- TypeScript 검사, 배포 빌드, 변경사항 공백 검사 통과. 기존 대형 장면 청크 안내만 남아 있습니다.
- 독립 리뷰에서 초기 공격 시 가림, 움직임 줄이기 상태의 뿅망치 짧은 타격, 모서리 이동 정지를 발견하고 수정 확인했습니다. 추가 313개 순찰/시작 위치 조합에서 정지·가구 침범·간격 1.05 미만 사례가 없었습니다.
- 브라우저에서 세 도구의 공격, 커피 제조·마시기, 쿠키 챙기기·먹기, 탕비실 착석·기대기를 조작했습니다. 주머니가 동작 중 숨겨지고 종료 후 돌아오며 커피 3→2모금, 쿠키 1→0개가 되는 것을 확인했습니다.
- 기본 세로 화면과 1280×800 화면에서 확인했습니다. 브라우저 경고·오류 기록은 비어 있었습니다. 검사 후 화면 크기 설정을 복원했습니다.

실제 휴대전화 하드웨어 성능/FPS는 측정하지 않았습니다. 검증 당시 배포 전 개발 화면을 사용했으며, 최종 GitHub 커밋과 배포 결과는 해당 서비스 응답으로 별도 확인합니다.
